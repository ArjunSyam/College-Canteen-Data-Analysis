# College Canteen Data Analysis

## Project Overview

Our college team conducted a comprehensive analysis of the campus canteen ecosystem to better understand its dynamics during peak hours. Recognizing the challenges of overcrowding and service efficiency, we collected data directly from fellow students using structured surveys.

The data collection process involved distributing Google Forms to a diverse sample of the student population. After collection, we performed thorough data cleaning procedures to ensure accuracy and consistency in our dataset.

The cleaned dataset was then analyzed across multiple metrics including:
- canteen rating
- Average waiting timee
- Average spending 
- Gender
- Veg/Non Veg
- Prefered cuisine and go to beverage

This analysis aims to provide valuable insights that can help optimize canteen operations and improve the overall dining experience for the college community.
